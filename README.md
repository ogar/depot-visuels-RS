# depot-visuels-RS

Dépôt de passage : les visuels des publications de l'artiste, redimensionnés pour les réseaux, le temps que l'outil de programmation vienne les chercher. Chaque fichier est retiré après parution et l'historique est réécrit. Rien ici n'est une œuvre ni une archive : les originaux vivent ailleurs.
